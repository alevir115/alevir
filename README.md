# Client Ledger

Hola, podrias desarrollar una aplicacion web con base de datos local en SQL en donde se pueda administrar clientes (AGREGAR, QUITAR, MODIFICAR) y cada cliente cuente con estos campos: ID CLIENTE, APELLIDO CLIENTE, NOMBRE CLIENTE, CUIT CLIENTE Y TELEFONO CLIENTE
